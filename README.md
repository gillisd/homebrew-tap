# Gillisd Testtap

## How do I install these formulae?

`brew install gillisd/testtap/<formula>`

Or `brew tap gillisd/testtap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "gillisd/testtap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
